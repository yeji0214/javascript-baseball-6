# 숫자 야구 ⚾️

### 구현할 기능

- [X] 게임 시작 문구 출력
- [X] 컴퓨터 - 3자리 수 생성
    - [X] 1부터 9까지의 서로 다른 랜덤 수
- [X] 사용자 입력 - 3자리 수
    - [X] 1부터 9까지의 서로 다른 수
    - [X] 예외 처리
        - [X] 범위를 벗어난 숫자가 있는 경우
        - [X] 숫자(정수)가 아닌 값이 있는 경우
        - [X] 중복된 숫자가 있는 경우
        - [X] 3자리가 아닌 경우
- [X] 숫자 비교 & 결과 표시
    - [X] 스트라이크 - 같은 수가 같은 자리에 있는 경우
    - [X] 볼 - 같은 수가 다른 자리에 있는 경우
    - [X] 낫싱 - 같은 수가 전혀 없는 경우
    - [X] 볼과 스트라이크가 공존하는 경우 볼, 스트라이크 순서로 표시
- [X] 결과에 따른 게임 진행 여부 결정
    - [X] 3 스트라이크인 경우, 게임 종료 -> 게임 재시작 여부 입력 받기
    - [X] 그 외의 경우, 게임 계속 진행
- [X] 사용자 입력 - 재시작 여부
    - [X] 1 입력 시, 게임 재시작
    - [X] 2 입력 시, 게임 종료
    - [X] 예외 처리
        - [X] 1 또는 2가 아닌 다른 숫자를 입력한 경우
        - [X] 숫자가 아닌 경우
        - [X] 정수가 아닌 경우
